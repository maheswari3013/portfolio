StudySync – Automated Timetable Planner

A dynamic React + Node.js student timetable application that replaces static calendars with smart, automated, self-healing schedules. It uses custom heuristics to structure study hours based on difficulty, priority, and knowledge levels, and dynamically auto-reschedules missed sessions via server background tasks.

Key Architecture Features:

  • Self-Healing Engine: Background cron jobs detect missed sessions and automatically reschedule them to avoid overlaps.
  • Web Push Notifications: Direct browser push reminders and analytics digests triggered by backend events.
  • Google Sync: Seamless two-way integration with Google Calendar API using OAuth 2.0.
  • On-Demand Export: Dynamic layout PDF generation built directly on the server side using PDFKit.
